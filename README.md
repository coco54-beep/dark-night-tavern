# 暗夜酒馆 · AI 文字 RPG 引擎

一个可自托管的 AI 文字冒险游戏引擎：把长篇小说变成可以持续游玩的世界，带人物状态、欲望/好感、任务、经济、知识边界和 NPC 自主行动。

这个仓库**只包含引擎**，不包含任何小说全文、故事圣经、存档或 API 密钥。书库由使用者自行导入。

## 特性

- **长篇小说锚定**：导入 TXT 后可按 4 万字分段生成故事圣经（人物、关系、伏笔、时间线、结局），游戏按原文窗口推进。
- **状态机**：好感、亲密度、欲望、体力、声望、通缉、经济、职业、任务、物品、关系网。
- **NPC 自主性**：自己的作息与目标，会主动、会离开；主动者有冷却与轮换。
- **知识边界**：不在场的人不会凭空获得私密信息；独处时不会有人硬闯。
- **单人模式**：无登录、无云端存档，AI 直连；适合本地或 APK 使用。
- **预置写实头像**：46 张本地生成的 NPC 头像（人类 + 动物/外星/机械/灵体/兽人/龙/魔），按性别/年龄/物种自动匹配\n- **成人向机制**：包含亲密与欲望系统，默认面向 18+ 用户；仓库不附带任何露骨文本。

## 快速开始

要求：Node.js 18+。

```powershell
node serve.js
```

浏览器打开 `http://localhost:5012`。

首次使用：

1. 点首页「我的 AI」，填写 API 地址、模型名、密钥（兼容 OpenAI Chat Completions 的服务）。
2. 导入自己的 TXT（≤ 5 MB、≤ 50 万字符），选择「生成故事圣经」或「直接开始」。
3. 之后每一幕自动保存；「我的旅途」可继续。

也可以用环境变量配置 AI：

```powershell
$env:TAVERN_LLM_BASE="http://127.0.0.1:8000/v1"
$env:TAVERN_LLM_MODEL="your-model"
$env:TAVERN_LLM_KEY="your-key"
node serve.js
```

或复制 `.env.example` 中的字段，写入 `data/llm.local.json`（`data/` 已被 git 忽略）。

## 书库

仓库默认 `worlds-index.js` 为空。推荐在游戏内用「导入 TXT」：

- 文件 ≤ 5 MB，正文 ≤ 500,000 字符
- 可生成全书概要、故事圣经或直接开始
- 故事圣经按 4 万字并行分析，长书需要几分钟
- 上传成功后自动进入首页「我的书」，可以再次打开、沿用已生成的故事圣经重新开始

超过 50 万字符或想作为“内置书”加载，见 [docs/IMPORT_BOOKS.md](docs/IMPORT_BOOKS.md)。

**只导入你拥有权利或已获授权使用的文本。** 不要提交或分发受版权保护的小说。

## 存档与隐私

- 单人模式使用浏览器 `localStorage`，不上传服务器。
- `data/` 保存账号、设置与存档，已被 `.gitignore` 排除。
- 仓库不包含任何遥测；AI 请求只会发送到你配置的接口。
- 公开部署前请自行增加 HTTPS、访问控制、速率限制与内容审核。

## APK
